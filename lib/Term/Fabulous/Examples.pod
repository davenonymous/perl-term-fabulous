=head1 NAME

Term::Fabulous::Examples - The example programs of the distribution,
with pictures

=head1 DESCRIPTION

The distribution comes with three directories of runnable programs:

=over

=item F<examples>

Demo programs, each showing off one area of Term::Fabulous; see
L</THE DEMO PROGRAMS>.

=item F<examples/widgets>

One small program per widget, showing it in its typical states; see
L</THE WIDGET GALLERY>.

=item F<examples-cookbook>

The complete programs of L<Term::Fabulous::Cookbook>, one file per
recipe; see L</THE COOKBOOK PROGRAMS>.

=back

Every picture on this page shows a program running in a terminal,
taken from the shipped file after the input that is described next to
it. The pictures are taken again whenever a program changes, so they
always show what the code does.

=head1 RUNNING THE EXAMPLES

The programs need a terminal that uses a UTF-8 locale and supports
24-bit colors (see L<Term::Fabulous::Manual/REQUIREMENTS>). Interactive
programs take over the whole terminal; Ctrl+C ends any of them.

To get the files, unpack the distribution, for example with
C<cpanm --look Term::Fabulous>. Once Term::Fabulous is installed, run a
program from the unpacked directory:

	perl examples/form.pl

Without installing it, build the distribution first and run the
programs with the built copy:

	perl Makefile.PL && make
	perl -Mblib examples/form.pl

=head1 PICTURES OF YOUR OWN PROGRAMS

The pictures on this page are taken with F<tools/screenshot> from the
distribution, which takes one of any Term::Fabulous program, as SVG or
PNG. It runs the program in a pseudo terminal of a given size, sends it
the keys, text and mouse actions you give, and records what the
terminal shows. Time is simulated, so animations and clocks come out
the same on every run. From a built copy of the distribution:

	perl -Mblib tools/screenshot --size 100x30 --output form.svg examples/form.pl
	perl -Mblib tools/screenshot --steps 'type "Ada"; key "Tab"' --output form.png my-program.pl

C<perl -Mblib tools/screenshot --help> lists the options. PNG output
needs L<Imager> with PNG and FreeType support; F<tools/README.md>
describes the tools.
